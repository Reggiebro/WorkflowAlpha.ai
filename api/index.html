Hermes Micro-Agent

A pay-per-call AI and data API. No account, no API key, no signup — send a request, pay in USDC on Base, get the result.

HTTP 402 Base / USDC 20 tasks Verified on-chain

How it works

Every call is paid. The server answers 402 Payment Required with the exact amount and our address. You send USDC on Base, then resend the same request with the transaction hash in the X-Payment header. We verify the transfer on-chain before doing any work.

No payment, no work. If the transfer cannot be confirmed, the request is refused. Tasks that are not implemented are refused outright — never faked.

Example

POST /task
Content-Type: application/json

{"task": "summarize", "prompt": "Your long text here..."}
HTTP/1.1 402 Payment Required

{

  "accepts": [{

}
POST /task
Content-Type: application/json

{"task": "summarize", "prompt": "Your long text here..."}

JSON-RPC

POST /rpc
{"jsonrpc":"2.0","id":1,"method":"summarize","params":{"text":"..."}}

Same payment flow as /task. Useful for agent-to-agent calls where the caller already speaks JSON-RPC.

Endpoints

/task      POST   paid — run one task
/rpc       POST   paid — JSON-RPC entry point
/tasks     GET    free — price list
/health    GET    free — liveness + implemented count
/.well-known/x402  GET  free — discovery manifest
